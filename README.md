# 🌌 IBRA Services Fusion - Unified AI Automotive Ecosystem

Welcome to the unified repository for **IBRA Services Inc.** projects. This "Fusion" combines advanced AI model merging with comprehensive automotive management systems.

## 🚀 Overview

This ecosystem is composed of four main pillars:

1.  **[Heptafusion & Ibra-OS](projects/heptafusion-open/README.md)**:
    - **Heptafusion**: Advanced LLM merging (SLERP, DARE) to create specialized "Brain IA" models.
    - **Ibra-OS Swarm**: A multi-agent system (Secretary, Vision, Physics) for autonomous garage operations.
    - **Cyber HUD**: High-fidelity terminal interface for real-time monitoring.

2.  **[IBRA Services Fullstack](projects/ibraservices/README.md)**:
    - Next-gen garage management featuring a PWA with offline support.
    - Integrated AI Chatbot, Loyalty Program (4 VIP levels), and Digital Vehicle Passports.
    - Advanced analytics and automated billing/accounting.

3.  **[GaragePilot AI (IAPilot)](projects/ibraservices-iapilot/README.md)**:
    - Focus on AI-driven diagnostics and predictive maintenance.
    - Tailored interfaces for both garage staff and customers.
    - SOS messaging and real-time inventory tracking.

4.  **[Ibra Pro Garage (Facture)](projects/ibrapro-facture/README.md)**:
    - Specialized invoicing and billing module for garage workflows.
    - Client and product management with focus on simplicity and efficiency.

## 🌐 Symbiotic Architecture

IBRA Services operates on a circular, ethical, and radically technological model:
1. **BioFlux**: Mimetic sensors translate physical machine "vital signs" into **HDF5** data.
2. **Heptafusion**: Advanced **Gemma 4** MoE architecture learns from this data.
3. **Ibra-OS**: Autonomous agents (The Swarm) apply this intelligence to real-world maintenance.
4. **Social Model**: AI-generated value enables free services for those in need.
